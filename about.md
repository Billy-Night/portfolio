## Project Process

The approach varies by project, but typically follows four phases:

### 1. Discovery

Billy discusses the client's goals, requirements and challenges, researches competitors, explores possible solutions and design directions, and creates mood boards to establish the project's direction.

### 2. Design

Billy presents a style guide with typography and colour options, creates low-fidelity wireframes, and develops high-fidelity designs once the initial direction is approved.

### 3. Development

Billy builds the website or application using reusable components and a responsive layout system. This includes optimising images and fonts for web performance and adapting the experience to major device sizes.

### 4. Deployment

Billy connects the domain, configures SSL and launches the website. He then checks stability, SEO, performance and accessibility using tools such as Google Search Console, Ahrefs and Lighthouse.
